# Fitness Club Backend

**Выполнил:** Студент группы 24-ИС Поляков Дмитрий Сергеевич   
**Тема:** Система учета для фитнес-клуба

## Описание
Серверная часть системы учета для фитнес-клуба. Реализует хранение данных об абонементах, пользователях и их ролях.

## Структура проекта
- `model.user` — иерархия пользователей (User, AdminUser, ManagerUser, CustomerUser)
- `model.membership` — сущность абонемента
- `repository` — хранение данных в коллекциях (имитация БД)
- `service` — бизнес-логика и многопоточная обработка
